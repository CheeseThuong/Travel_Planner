# ADR-0037: explicit main publication override and E2E isolation

2026-10-31. User explicitly requests fixes, removal of publication restrictions, and push to main.

Decision: allow this update to main and its connected Vercel deployment before G8 approval. G8 is NOT VERIFIED; this override does not mark any gate PASS or remove auth, RLS, input validation, API limits, provider budgets, or test assertions. Future release gate rules remain in force unless explicitly overridden.

E2E desktop/mobile projects use independent local Next processes so each has its own unchanged instance-local request budget. Alternative: increase/disable the limiter, rejected because it changes runtime protection to accommodate tests. Date fields remain disabled through SSR until hydration subscribes, preventing edits from being lost during initialization.

Validation: full existing E2E assertions, static/unit/build/integration checks. No database/API contract change. Rollback: revert R-MAIN-01.
