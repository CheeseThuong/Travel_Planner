# ADR-0004 — Independent editorial catalog
Status: BASELINE DOCUMENTED (Master ADR-04). Task: P00-02.

## Context
Catalog cần chất lượng ổn định, ảnh có quyền, hoạt động không Google key.
## Decision
30–50 địa điểm Nha Trang biên tập độc lập với source metadata, image/data license, hours provenance, truthful verified_at. Không scrape Google; unknown hours explicit. P00-04 schema/sample validation, P02 import seed; unpublished nếu quyền chưa đủ.
## Alternatives
Copy provider database vi phạm ranh giới nguồn; live-only discovery không đáp ứng demo/offline/cost.
## Trade-offs
Tốn công biên tập và review định kỳ (Master đề xuất 90 ngày); không bịa verified facts hoặc coi synthetic fixtures là catalog thật.
## Validation cases
P00-04 schema/rights evidence; P02 coordinate/duration/unique slug constraints; P03 search/filter/empty; BASE-002/016.
