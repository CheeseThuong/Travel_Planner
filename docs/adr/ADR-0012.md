# ADR-0012 — Open-source catalog and original symbolic illustrations
Status: CONTENT DESIGN PROPOSAL — prepared under user's 2026-10-21 authorization to research open sources and create original illustrations; G0 dataset strategy review pending.
Task: P00-04 / RIGHTS-001.

## Context
Initial repository contained no real editorial records or licensed assets. User chose independent open sources and original illustrations. Wikidata query service returned an outage-related 429; a bounded Overpass read of OpenStreetMap succeeded.

## Decision proposed for G0
Use a separately identified OSM-derived Nha Trang catalog database with 30 edited draft records under ODbL-1.0, retaining attribution/source/version and editable data snapshot/rebuild script. Do not apply the database license to private trips or assume it licenses images. Six project-original geometric category SVGs have commissioned project-use authorization; final city/landmark artwork remains P07. No runtime OSM provider, map tiles, package or architecture change.

## Alternatives
Wikidata CC0: simpler database licensing but query unavailable during acquisition. User-supplied facts/photos: not provided and user selected research. Google scrape: prohibited. Synthetic records: useful tests, insufficient real editorial seed evidence.

## Trade-offs
OSM-derived database creates attribution/share-alike distribution obligations. Keep derived database/source download available and document license before public catalog use. User must approve this concrete catalog licensing strategy at G0; failure to approve leaves G0 NOT VERIFIED, without forcing an architecture choice. Community coordinates may be stale/centroid-only. Draft status and explicit uncertainty must survive P02 mapping. Own symbolic SVGs avoid copied photos but do not satisfy P07 landmark art quality by themselves.

## Updated test cases and contracts
P00: schema and negative validation, 30 unique source identities/UUIDs/slugs, source-coordinate/version matching, 30 image evidence links, all hours unknown and source-only timestamps, no provider Google fields. P02: migration mapping preserves provenance/licenses and draft/published distinction. P03: displayed OSM attribution plus ODbL/source-download links. P07: image metadata/alt text and original-art review. No API/DB schema has been silently changed; these are content-import acceptance requirements.

## Rollback
Remove OSM-derived catalog/snapshot and generated category assets; retain acquisition failure evidence and schema proposal if helpful. Replace with independently licensed source records and repeat P00-04 checks before G0. Never substitute fake records or strip attribution to make validation pass.
