# ADR-0003 — IndexedDB via Dexie
Status: BASELINE DOCUMENTED (Master ADR-03). Task: P00-02.

## Context
Người dùng cần giữ draft qua refresh và offline, không chỉ React memory.
## Decision
Dexie IndexedDB cho drafts/pending mutations/settings/catalog dự án có quyền. Debounce write, rehydrate, versioned schema upgrade; cloud canonical sau save. Stale version yêu cầu reload server hoặc giữ local thành copy; không tự merge. Reconnect queue phải hiển thị xác nhận.
## Alternatives
Memory-only mất draft; localStorage không phù hợp transaction/schema; cloud-only không đáp ứng offline.
## Trade-offs
Browser quota/eviction/private mode không bảo đảm lưu vĩnh viễn. Clear-local action và sync state cần rõ; không cache restricted provider content.
## Validation cases
P05 T-017/018/019: reload/offline/reconnect/two-tab/schema upgrades; privacy clear cache; AC-008/013.
