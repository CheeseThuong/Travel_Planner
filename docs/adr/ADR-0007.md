# ADR-0007 — Read-only sharing
Status: BASELINE DOCUMENTED (Master ADR-07). Task: P00-02.

## Context
Người có mã cần xem lịch từ thiết bị khác; mã không phải owner credential.
## Decision
CSPRNG >=128 bits, Crockford Base32 format được kiểm thử; hash/HMAC server only, plaintext chỉ response create. Resolve POST body; fragment URL tránh token vào request URL; redact log/analytics, no-referrer shared view. Owner auth tạo/revoke; strict rate limits, sanitized response không owner/private fields. Invalid generic error, revoked/expired theo contract đã review.
## Alternatives
UUID trip public/short guessable code hoặc share token cho edit phá isolation.
## Trade-offs
Code lộ cho phép xem đến revoke; không thể list lại plaintext hoặc phục hồi quyền sửa. API-002 wording cần resolution trước G0.
## Validation cases
P06 entropy/storage/collision/rate-limit/revoke/expiry/cross-device tests; AC-009/010/011; unauthorized mutations fail even with valid token.
