# ADR-0033 — On-demand native OSM pin picker

Status: implementation detail under approved Discovery/interactive-map request,2026-10-30. No dependency, production deployment or guaranteed map-service approval.

Use a small native browser raster tile/pin widget with pure Web Mercator geometry instead of a new map SDK for the bounded pick-one-location flow. It loads only after an explicit user action and a notice that the viewed region is sent to OpenStreetMap. No geolocation permission or current GPS lookup. Name/address search remains our independent local catalog/provider pathway; do not call public Nominatim or proxy arbitrary URLs.

Reviewed [OSMF raster tile policy](https://operations.osmfoundation.org/policies/tiles/) and [OSM copyright/ODbL](https://www.openstreetmap.org/copyright). Use canonical HTTPS tile URLs, visible linked contributor attribution and map-issue link. Browser default User-Agent/caching and `strict-origin-when-cross-origin` referrer identify the app without sending page/query details. At most9 currently visible tiles per view; no prefetch, offline packs, forced no-cache, server proxy, unattended pan/zoom or hidden tile traffic. Browser tests intercept all tile URLs with fixtures; never automate against the community tile service.

Keep manual advanced coordinates, catalog selection and schedule generation available on map/network failure. Keyboard pan, Enter/Space pin placement, zoom and separate explicit location confirmation accompany pointer/touch input. No animated map transition or WebGL/3D dependency. The selected point is user-entered geography, not a surveyed entrance or verified provider business. Never fill/save a Google camera coordinate or Brave content as independently owned data.

Alternatives: new map SDK/dependency, unrestricted tile URL, public geocoder, automatic tile loading or downloadable city packs (rejected for this slice). Public OSM service has no SLA; higher usage, alternative tile provider, contact/hosting arrangements and future policy review remain release concerns. Provider configuration/hosting can change only with a reviewed policy boundary; no silent arbitrary URL switching.

Verify roundtrip/clamp/world-wrap math, tile bounds/count, invalid coordinates/zoom, no pre-action network, attribution/referrer/caching shape, pointer/keyboard selection and failure/offline retention at mobile/desktop. Rollback widget/math/import/test hunks; no DB, keys or legacy data migration.
