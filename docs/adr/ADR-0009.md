# ADR-0009 — Progressive playful visuals
Status: BASELINE DOCUMENTED (Master ADR-09). Task: P00-02.

## Context
Chibi/2.5D giúp bản sắc nhưng không được chặn editor hoặc mobile accessibility.
## Decision
Motion cho interaction, GSAP landing effects; Three.js/R3F chỉ optional lazy feature flag. Core itinerary usable without 3D; reduced-motion branch, keyboard alternatives. Palette/font ở Master 15 là draft, chưa chốt AA hoặc license khi chưa kiểm chứng.
## Alternatives
3D toàn trang tăng chi phí và khả năng block core; animation-only interaction loại keyboard/reduced-motion users.
## Trade-offs
Bundle/performance budget phải đo; không cài graphics dependency sớm. Asset/font license review trước đưa vào app.
## Validation cases
P07 T-026/027, axe/keyboard/contrast 360px, no asset CLS, Lighthouse >=80 trên 3 trang với điều kiện test cố định.
