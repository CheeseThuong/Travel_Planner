# ADR-0018 — Phase01 contracts and configuration baseline

Status: ACCEPTED implementation detail under full implementation request,2026-10-21. No schema/planner/auth/gate waiver. P01-01 closed; P01-02..04 only.

Trip/route/persistence ports express Master single-destination, versioned candidate/apply and directed/unreachable/provenance boundaries. No runtime planner/provider/storage or owner-auth behavior is claimed. Persistable stop coordinates are editorial/user-entered; a Google reference does not become unrestricted provider content. Synthetic fixture adapter is explicitly test-only. Domain imports are restricted to domain through lint and AST tests.

Server configuration consumes `CLOUD_ENABLED` and `GOOGLE_MAPS_LIVE_ENABLED` with default false. Canonical Google secret is Master `GOOGLE_MAPS_SERVER_KEY`; earlier .env.example name was reserved/unimplemented, so replace it before introducing consumers. Cloud configuration must be complete to enable; Google live needs key and explicit positive budget. `DEPLOYMENT_ENV=production` must opt into configured cloud. Preview/local builds without secrets remain valid. No server values are added to next.config.env or client flags. Zod4.6.7 MIT, server-only use here; no intentional initial client bytes.

Add only existing-contract `GET /api/v1/health` at this stage: liveness `{data:{status:'ok'},meta:{request_id}}`, no backend/provider/ownership readiness assertion. Header request IDs accept UUID only; otherwise generate new UUID. Shared error helper follows400 malformed JSON/422 schema,413 bounded body and generic500, no raw exception/provider/token output. Log only validated fixed event/code/request-id/status/duration fields; never request bodies/URLs/secrets. Future endpoints reuse foundation but are not fabricated now. OpenAPI lists only implemented health; Master retains remaining endpoint requirements.

Alternatives: accepting partial credentials makes configuration ambiguous; exposing whole env/errors leaks secrets; accepting arbitrary request IDs can echo token text; memory mocks are not real database security. API-only initialization misses broken build config, so Next config validates server env without serializing it. Rollback task-only helpers/health/config/OpenAPI/Zod pin; preserve private data (none exists yet).

Tests: no-key local/partial/production/budget failures, redaction with injected sensitive values, UUID spoofing, malformed/schema/oversize JSON, unknown exception generic output, real HTTP health, domain boundaries and deterministic fixture adapter. CI builds and exercises only local app with live flags OFF; no production requests or Google calls. Actual remote result required before G1 PASS.
