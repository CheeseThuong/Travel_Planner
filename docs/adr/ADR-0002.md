# ADR-0002 — Supabase PostgreSQL and Auth
Status: BASELINE DOCUMENTED (Master ADR-02). Task: P00-02.

## Context
Cloud trip cần owner isolation, transactions, schema constraints và guest-first save.
## Decision
PostgreSQL Supabase + Auth; tạo anonymous authenticated session khi Save, local-only trước đó. Verified server auth + RLS cho tất cả trip-owned data; không tin owner_id client. expected_version và idempotency bảo vệ mutation atomic. Share qua constrained server path, không public owner API/service key client.
## Alternatives
Public anon CRUD không có ownership; tự dựng auth tăng rủi ro và vận hành.
## Trade-offs
Anonymous credentials mất có thể mất quyền sửa; read token không phục hồi owner. Supabase local/Docker cần xác minh P02; account upgrade P1.
## Validation cases
P02 pgTAP null auth/A/B/forged owner tests, replay blank migrations; P05 rollback atomic/version conflict; AC-011/013 và T-020/021/025.
