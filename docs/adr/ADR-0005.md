# ADR-0005 — Optional bounded Google adapters
Status: BASELINE DOCUMENTED (Master ADR-05). Task: P00-02.

## Context
Provider tăng độ hữu dụng nhưng có billing, availability và terms constraints.
## Decision
External calls ở adapters sau interfaces; pure domain không Google SDK. Mock/approximate default; live OFF tới khi policy/key/quota/budget được review. URL import allowlist HTTPS, hop/DNS/network validation hoặc manual fallback không fetch. User xác nhận candidates; không bảo đảm URL luôn resolve.
## Alternatives
Domain gọi SDK trực tiếp làm engine khó test; arbitrary link fetch không an toàn; live bắt buộc phá demo/no-key requirement.
## Trade-offs
Approximate route có uncertainty và mode limits; directed matrix và unreachable không được âm thầm coi là hợp lệ.
## Validation cases
P03 SSRF/unsupported/ambiguous links; P04 quota/timeout/429/missing-key directed matrix tests; T-006/007/012..016/028/029.
