# ADR-0001 — Next.js App Router, TypeScript, Vercel
Status: BASELINE DOCUMENTED (Master ADR-01). Task: P00-02.

## Context
MVP cần full-stack stateless, mobile UI, API và không tự vận hành dedicated server.
## Decision
Giữ Next.js App Router, strict TypeScript, Vercel. Chọn stable version và kiểm tra advisories/license tại P01, không chọn version từ trí nhớ. API Route Handlers server-side validate input/request ID; functions có bounded work, không persistent worker.
## Alternatives
SPA + backend riêng tăng vận hành; persistent jobs chỉ xem xét qua ADR mới khi timeout không đủ.
## Trade-offs
Phụ thuộc hosting/function limits; cần kiểm tra plan phù hợp trước commercial deployment. Không có deployment ở P00.
## Validation cases
P01 typecheck/lint/build + route smoke; NFR-03 benchmark phân biệt CPU/network; P08 environment separation, function limits và rollback.
