# ADR-0013 — User-requested Đà Lạt catalog extension
Status: ACCEPTED — explicit user request in chat 2026-10-21: confirm G0, continue building and add Đà Lạt places.
Tasks: P00-05, P01-01, future P02-01/P03-01.

## Context
ADR-0008/Master ADR-08 deferred other provinces until Nha Trang MVP. The user's current request takes precedence and explicitly adds Đà Lạt. G0/ODbL review from the previous turn is now accepted.

## Decision
Add a separately sourced 30-record Đà Lạt editorial draft catalog under the same approved ODbL/provenance/original-symbolic-image controls. Single-trip destination remains one city; no intercity optimization. Include Đà Lạt in data-driven destination metadata, route skeleton and later catalog/seed acceptance. Keep timezone explicit per destination. Never mix Nha Trang and Đà Lạt coordinates/records in a single catalog or trip selection.

P00-05 is a PARALLEL-OK content acquisition extension after accepted G0, independent of scaffold and blocking destination seed/catalog publication at P02/P03. It does not reopen the approved architecture/license policy or permit skipping G1/G2. Original Nha Trang P00-04 evidence remains historical and unchanged; Đà Lạt gets separate schema/snapshot/validator/report.

## Alternatives and trade-offs
Deferring all Đà Lạt work ignores the request. Mixing cities in one trip expands planner scope and is rejected. Reusing city-specific facts without source evidence is rejected. Separate data increases content/testing work but requires no provider, database technology or architecture change.

## Updated validation cases
Validate 30 Đà Lạt drafts against their source/version/coordinate bounds, unique IDs and Nha Trang separation, unknown-hours/rights evidence. P01 skeleton recognizes both destination slugs and 404s unsupported ones. P02 seed and P03 filters must isolate destination_id. Future planner refuses mismatched-city selected records rather than silently combining cities.

## Rollback
Remove Đà Lạt extension from metadata/routes/content and revert this explicit scope amendment only with recorded user decision; retain Nha Trang functionality and source evidence. No migration exists yet.
