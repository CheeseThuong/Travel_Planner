# ADR-0016 — Recovery audit and scaffold typography correction

Status: ACCEPTED scope under explicit full implementation/recovery request, 2026-10-21. No gate waiver, dependency override, schema/API/engine change or deployment authorization.

## Context and decision

The user requests an audit, actual Vietnamese typography repair, and full product implementation with G0–G8 preserved. Existing P01 support blocker remains applicable. R0-01 audit and R1-01 repair of the existing scaffold are independent corrections within Phase01, permitted by that explicit request. They do not implement dependent catalog/wizard/planner/persistence/share phases or complete P07.

Inspect rendered typography before changing styles. Prefer self-hosted unmodified Be Vietnam Pro for UI and Nunito normal/italic for headings, with full Vietnamese coverage, reviewed OFL notices and recorded checksums. Use next/font/local to avoid build/runtime Google font requests and permit credential-free/offline builds. This is a licensed asset change, no npm dependency or architectural stack change. Measure transferred bytes, glyph selection, wrapping and font-load layout shift; do not assert success from font family names alone.

## Alternatives and trade-offs

Keep system Georgia/Arial: platform-dependent glyph fallback and no stable font metrics. next/font/google: fits the stack but requires network at build acquisition. Character splitting/normalization workarounds: inappropriate unless inspection finds that root cause. A new generic dashboard or additional animation work would distract from P0 repairs.

## Verification and rollback

Before/after platform-font evidence and screenshots; all Vietnamese precomposed letters and combining marks must be covered in every shipped face. Render actual routes plus explicit NFC/NFD/style samples on Chromium/Firefox/WebKit at six widths. Check delayed/failed fonts, no-JS, reduced motion, no overflow, CLS and existing demo regressions. R1 completion does not establish G1/G7/G8 PASS. Roll back task-only font imports/styles/assets while preserving historical evidence and existing features.
