# ADR-0000 — Separate task completion from phase approval

Status: ACCEPTED — user explicitly approved in chat on 2026-10-21.
Task: P00-01 / GOV-001.

## Context

AGENTS.md and MASTER_PLANNER 19.2 required the current gate PASS before task DONE. WORK_ITEMS requires completed predecessors before dependent tasks and all P00 tasks complete before G0 approval. This creates a cycle at the first task.

## Decision

Task DONE requires all task acceptance checks and applicable tests PASS with recorded evidence and closed task dependencies. A phase gate PASS additionally requires all blocking tasks DONE and gate review evidence. No later phase begins until the previous gate PASS. Failing or unverified gate checks cannot be bypassed by task completion.

## Alternatives

- Keep literal cycle: cannot close P00-01 or start dependent work.
- Start dependent work without closure: violates dependency discipline.
- Weaken phase gate: rejected; would allow unverified progression.

## Consequences and updated checks

Only bookkeeping rules change in AGENTS.md and MASTER_PLANNER 19.2. No API, schema, security boundary, engine assumption or dependency changes. P00-01 verification must assert both task completion conditions and the retained gate prohibition. G0 stays NOT VERIFIED until all P00 task and review requirements pass. Rollback restores original wording but reintroduces GOV-001.
