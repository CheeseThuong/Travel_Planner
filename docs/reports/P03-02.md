# P03-02 — Planner input wizard

2026-10-22. Status DONE. Depends on P03-01 DONE.

`/plan/new` is now an operational client-side wizard for Nha Trang and Đà Lạt. It captures dates, group size, transport, pace, whole-VND total/known costs, selected catalog stops and the explicit planning mode. The live summary uses the tested domain budget function to show remaining known budget and per-person/day allowance while keeping selected-place costs marked unknown.

Manual mode is a first-class choice. Its result states that selection order remains for the traveler to arrange; assisted mode only prepares input for the later deterministic planner and does not claim routing accuracy. Data remains a local unsaved draft until the P05 persistence phase.
